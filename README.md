# WebSocket Real-Time Chat
Aplicación de chat en tiempo real utilizando WebSockets

## Introducción
Este proyecto consiste en el desarrollo de una aplicación de chat en tiempo real utilizando tecnología WebSocket, permitiendo la comunicación instantánea entre múltiples usuarios conectados al servidor.

El sistema fue desarrollado como parte de una actividad académica con el objetivo de aplicar conceptos de comunicación cliente-servidor, programación en tiempo real y desarrollo web. La aplicación permite el envío y recepción de mensajes en tiempo real, además de incluir funcionalidades adicionales que mejoran la experiencia del usuario.

## Objetivo
Desarrollar una aplicación de chat en tiempo real mediante el uso de WebSockets, implementando funcionalidades básicas de comunicación cliente-servidor y complementos adicionales que permitan mejorar la interacción entre usuarios.

## Requisitos.
Para ejecutar correctamente el proyecto se requiere:
- Node.js instalado.
- Navegador web moderno (Google Chrome, Microsoft Edge, Firefox, etc.).
- Conexión a internet o red local para pruebas entre dispositivos.
- Librería `ws` para el manejo de WebSockets.

## Infraestructura
El sistema utiliza una arquitectura cliente-servidor.

### Servidor
El servidor fue desarrollado utilizando Node.js y la librería `ws`, encargándose de:
- Gestionar conexiones WebSocket.
- Administrar usuarios conectados.
- Enviar y recibir mensajes.
- Gestionar mensajes privados y eventos del sistema.

### Cliente
El cliente fue desarrollado con:
- HTML
- CSS
- JavaScript

La interfaz permite:
- Conectarse al servidor.
- Visualizar mensajes en tiempo real.
- Ver usuarios conectados.
- Enviar mensajes públicos y privados.
